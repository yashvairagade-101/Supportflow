# SupportFlow — Requirements

## Objective
Build an AI-powered customer support platform
using React and Spring Boot microservices.

## Main users
- Customer
- Support Agent
- Platform Admin
- Company / Tenant

## Core features
- Authentication and role-based authorization
- Ticket creation, assignment and status management
- AI assistant using company knowledge documents
- Notifications for ticket updates
- Company subscription plans and payments

## Advanced engineering features
- API Gateway and service discovery
- Apache Kafka for asynchronous events
- Database design and transaction management
- Automated tests
- Docker and CI/CD
- Deployment and monitoring

## Project constraints
- Target completion: 15–20 days
- Prioritize a working end-to-end application
- Avoid unnecessary services and duplicate features
- Document implementation decisions and interview answers
